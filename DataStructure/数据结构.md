### 并查集

> 并查集是一种用于管理元素所属集合的数据结构，实现为一个森林，其中每棵树表示一个集合,  树中的节点表示对应集合中的元素。
>
> ——摘自 [OI wiki](https://oi-wiki.org/ds/dsu/)

并查集在竞赛中最常用的实现是: 

**把一个集合抽象为一颗树**.

并且树根为该集合的**代表元素**.

**所谓并:**  就是合并元素为一个集合, 合并的实现可以将两个集合共用一个代表元素.

**所谓查:**  就是查找对应元素在哪一个集合下.



##### 查找实现

一般情况下并查集使用数组实现, 其中数组`fa[]`通常用来记录每个节点的**父节点**

最简单的查找方法就是使用递归实现

```cpp
int fa[maxn];

int find(int x)
{
    if(fa[x]==x)
    return x;
    else return find(fa[x]);
}
```

但是这样的话多次查询就比较费力了(时间复杂度$O(nm)$)

所以我们有**路径压缩优化:** (时间复杂度接近于$O(1)$)

第一次查询时, 把所有子节点的父节点**全部标记为代表元素**

这样后面的查询只要一次就行, 但是会破坏树的结构. 但在并查集中我们不关心树的结构, 只关心**代表元素**

**路径压缩优化:**

```c++
int find(int x)
{
    if(fa[x]==x)
    return x;
    else return fa[x]=find(fa[x]); //递归返回的过程中统一父节点
}
```



##### 合并实现

合并就是共用两个集合的代表元素

```c++
x=find(x),y=find(y);
if(x==y) //如果已经是同一个集合的元素, 跳过操作
continue;
fa[x]=y; //合并顺序可以任意
```



##### 种类并查集

> S 城现有两座监狱，一共关押着 $N$ 名罪犯，编号分别为 $1\sim N$。他们之间的关系自然也极不和谐。很多罪犯之间甚至积怨已久，如果客观条件具备则随时可能爆发冲突。我们用“怨气值”（一个正整数值）来表示某两名罪犯之间的仇恨程度，怨气值越大，则这两名罪犯之间的积怨越多。如果两名怨气值为 $c$ 的罪犯被关押在同一监狱，他们俩之间会发生摩擦，并造成影响力为 $c$ 的冲突事件。
>
> 每年年末，警察局会将本年内监狱中的所有冲突事件按影响力从大到小排成一个列表，然后上报到 S 城 Z 市长那里。公务繁忙的 Z 市长只会去看列表中的第一个事件的影响力，如果影响很坏，他就会考虑撤换警察局长。
>
> 在详细考察了 $N$ 名罪犯间的矛盾关系后，警察局长觉得压力巨大。他准备将罪犯们在两座监狱内重新分配，以求产生的冲突事件影响力都较小，从而保住自己的乌纱帽。假设只要处于同一监狱内的某两个罪犯间有仇恨，那么他们一定会在每年的某个时候发生摩擦。
>
> 那么，应如何分配罪犯，才能使 Z 市长看到的那个冲突事件的影响力最小？这个最小值是多少？
>
> ##### 输入格式
>
> 每行中两个数之间用一个空格隔开。第一行为两个正整数 $N,M$，分别表示罪犯的数目以及存在仇恨的罪犯对数。接下来的 $M$ 行每行为三个正整数 $a_j,b_j,c_j$，表示 $a_j$ 号和 $b_j$ 号罪犯之间存在仇恨，其怨气值为 $c_j$。数据保证 $1\le a_j< b_j\leq N, 0 < c_j\leq 10^9$，且每对罪犯组合只出现一次。

上面这道题的人话就是将所有人分成两个集合(或者说是并查集), 两个集合边权的最大值最小.

这道题的一个解法的核心逻辑就是: **敌人的敌人就是朋友**

具体实现是:

1. 先把所有的 $w$ 从大到小排序, 随后开始遍历. 优先把边权较大的两个人分开.
2.  定义一个 $enemy$ 数组, 存储哪两个节点是敌人, 初值为0. 如果没有被赋值, 有如下操作

```cpp
if(!enemy[u])
	enemy[u]=v;
//......
if(!enemy[v])
    enemy[v]=u;
```

​		 如果被赋值, 就找到 $u$ 的敌人 $enemy[u]$ , 并将 $enemy[u]$ 与 $v$ 合并. 对于 $v$ 同理执行一遍.3. 

3. 在循环头部加上判断 $u,v$ 是否合并. 如果合并就把对应的边权和 $ans$ 比较, 取最大值, 从而得到最终答案. 

总实现如下:

```cpp
int n,m,ans;
int fa[maxn];
int enemy[maxn];

int find(int x)
{
    if(fa[x]==x)
    return x;
    else
    return fa[x]=find(fa[x]);
}
struct edge{
    int u,v,w;
};
vector<edge>qwq;

bool cmp(edge a,edge b)
{
    return a.w>b.w;
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0);
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    fa[i]=i;
    for(int i=1;i<=m;i++)
    {
        int u,v,w;cin>>u>>v>>w;
        qwq.push_back({u,v,w});
    }
    sort(qwq.begin(),qwq.end(),cmp);
    int cnt=n;
    for(auto x:qwq)
    {
        int u=x.u,v=x.v,w=x.w;
        if(find(u)==find(v))
        {
            ans=max(ans,w);
            continue;
        }
        if(enemy[u]==0)
        enemy[u]=v;
        else
        {
            int vvv=enemy[u];
            fa[find(vvv)]=find(v);
            cnt--;
        }
        if(enemy[v]==0)
        enemy[v]=u;
        else
        {
            int vvv=enemy[v];
            fa[find(vvv)]=find(u);
            cnt--;
        }
    }
    cout<<ans;
}
```

### 单调队列

此单调队列不是指 `priority_queue` 即大根堆或者小根堆, 而是手写的自由度较高的单调队列

> ##### 题目描述
>
> 有一个长为 $n$ 的序列 $a$，以及一个大小为 $k$ 的窗口。现在这个窗口从左边开始向右滑动，每次滑动一个单位，求出每次滑动后窗口中的最小值和最大值
>
> ##### 输入格式
>
> 输入一共有两行，第一行有两个正整数 $n,k$；\
> 第二行有 $n$ 个整数，表示序列 $a$。
> 
> ##### 输出格式
> 
> 输出共两行，第一行为每次窗口滑动的最小值；   
> 第二行为每次窗口滑动的最大值。

此例题每次操作的实现就是, 需要两个数组, 一个记录原始数组, 一个作为单调队列, 其中作为单调队列的数组存储的是元素下标. 同时需要双指针变量记录队头 `l` 和队尾 `r` . 

以求窗口最大值为例, 具体实现是这样的:

1. 每次向右滑动的时候, 检查队头元素的所在的下标位置, 如果超出了窗口的范围, 就把它踢出去.

```cpp
while(l<=r&&pos[l]<=i-k)
    l++;
```

2. 向右滑动加入元素的时候, 将新加入元素和队尾元素进行比较,如果队尾元素较小, 就弹出(等价于队尾指针前移), 同时继续比较直到队内元素大于新加入元素.

```cpp
while(l<=r&&num[pos[r]]<=num[i])
    r--;
```
3. 操作完成后, 我们需要更新队列 (即`pos[]`)
```cpp
pos[++r]=i;
```


4. 此时我们可以看出我们维护的是一个单调递减的序列, 队头元素一定是最大的. 可以准备输出

```cpp
if(i>=k)
cout<<num[pos[l]]<<"\n";
```



当然线段树也是可以用的, 但比较吃内存, 酌情使用.



### 单调栈

 与单调队列类似，单调栈维护的也是一种有序的数据结构。和单调队列的核心差异就是单调栈存储的是对于元素的下标，而不是元素本身。

单调栈有两种：

- 单调递减栈，指的就是栈内存放下标对应元素构成的序列对应的元素单调递减。
- 单调递增栈，指的就是栈内存放下标对应元素构成的序列对应的元素单调递增。

**P5788**模板题要求找到数组元素右边第一个大于它的元素

在寻找右边的时候，需要倒序遍历，以及一个数组 $R$ 存储下标

代码示例如下

```cpp
for(int i=n;i>=1;i--)
{
    //如果栈顶元素小于当前元素，就把它踢掉
    while(!st.empty()&&num[st.top()]<num[i])
        st.pop();
    //如果栈是空的，就说明不存在元素成立，反之设为经过筛选的栈顶
    R[i]=st.empty()?0:st.top();
    st.push(i);
}
```

一开始栈虽然是空的，但倒序遍历可以优先处理右边的元素，当我们处理第 $i$ 个时，它右边的所有元素都已经处理完了。

寻找左边的同理，只不过要改为正序遍历。



### 树

#### 二叉树

> 二叉树是每个节点最多只有两个子节点的特殊树, 所以使用如下方式存储
>
> ```cpp
> struct node{
>     int l,r;
> };
> node tree[maxn];
> ```

##### 求深度

给出一个二叉树, 最基础的求深度方式就是递归遍历. 一般来说根节点为1. 分别遍历左右节点.

求深度代码实现如下

```cpp
void dfs(int pos,int depth)
{
    int l=tree[pos].l,r=tree[pos].r;
    if(l==r&&l==0)
    {
        ans=max(ans,depth);
        return;
    }
    dfs(l,depth+1);
    dfs(r,depth+1);
}
```

##### 前中后序遍历

> ##### 输入格式
>
> 第一行一个字符串，表示该树的中序遍历。
>
> 第二行一个字符串，表示该树的前序遍历。
>
> ##### 输出格式
>
> 单独的一行表示该树的后序遍历.

关于树的遍历, 有很方便的口诀:

- 前序遍历: **根左右**
- 中序遍历: **左根右**
- 后序遍历: **左右根**

已知前中序求后序的方法通常用递归直接打印出来.

首先, 前序遍历的第一个元素一定是根节点. 通过这个元素找到中序遍历中的根节点位置, 此位置的左侧就是左子树, 右边就是右子树. 根据切出的子树长度去切前序遍历的左右子树, 由此递归下去. 两次递归结束后, 再输出根节点即可.

代码实现如下:

```cpp
void dfs(string zhong,string qian)
{
    if(zhong.empty()||qian.empty())
    return;

    char root=qian[0];
    int pos=zhong.find(root);
    string le=zhong.substr(0,pos);
    string ri=zhong.substr(pos+1);
    int l=le.length();
    string ple=qian.substr(1,l);//注意一定要跳过根节点
    string pri=qian.substr(l+1);//剩下的都是右子树

    dfs(le,ple);
    dfs(ri,pri);

    cout<<root;
}
```

##### 特殊情况

当我们知道一个树的前中序或者中后序时, 这个树是可以被唯一确定的. 但如果只知道前后序, 是不能唯一确定树的. 

但这种情况仅会出现在有某个节点仅存在一个儿子, 每有一个这样的节点, 中序遍历的个数便乘二.

> ##### P1229 遍历问题
> ##### 输入格式
>
> 共两行，第一行表示该二叉树的前序遍历结果 $s_1$，第二行表示该二叉树的后序遍历结果 $s_2$。
>
> ##### 输出格式
>
> 输出可能的中序遍历序列的总数，结果不超过 $2^{63}-1$。

##### 由遍历建树

已知前中序，建树实现如下：

```cpp
int n,idx=1;
int zhong[maxn],qian[maxn];
struct tree
{
    int l,r;
};
tree t[maxn];

int solve(int l,int r)
{
    if(l>r)
    {
        return 0;
    }
    int root=qian[idx++]; //全局指针，标记根节点位置
    int midpos=0;
    for(int i=l;i<=r;i++)
    if(zhong[i]==root)
    {
        midpos=i;
        break;
    }
    t[root].l=solve(l,midpos-1);
    t[root].r=solve(midpos+1,r);
    //注意返回值
    return root;
}
```



#### 树的直径

> ##### B4016 树的直径
>
> ##### 题目描述
>
> 给定一棵 $n$ 个结点的树，树没有边权。请求出树的直径是多少，即树上最长的不重复经过一个点的路径长度是多少。

最朴素的方法是使用两次dfs, 时间复杂度为 $O(n)$ **.**

1. **第一次DFS:** 从树上任意的一个节点开始, 找到离它最远的节点, 记录节点.
2. **第二次DFS:** 从记录的节点开始, 找到离它最远的节点, 此时的最远距离就是树的直径.

> 树是一个向四周发散的连通结构。无论你从哪个节点出发，顺着边走到尽头，一定会走到树的最边缘（叶子节点）。而树的直径两端点，必然是这棵树最外围的两个叶子节点。所以第一次 DFS 相当于先把你“拉扯”到了树的一个最远端点 $P$，第二次 DFS 则是从这一端彻底跨越整棵树，走到另一个最远端点 $Q$ .

存储方式使用无向图形式的邻接表. 值得注意的是, 使用DFS遍历时, 需要多搭配一个参数, 防止重复访问父节点. 

DFS实现如下:

```cpp
int n;
vector<int>qwq[maxn];
int mark[maxn];
int maxdep=-1;
int maxu;

void dfs(int u,int p,int depth)
{
    if(depth>maxdep)
    {
        maxdep=depth;
        maxu=u;
    }
    
    for(auto x:qwq[u])
    {
        if(x!=p)
        dfs(x,u,depth+1);           
    }
}
```

主函数如下:

```cpp
signed main()
{
    IOS;CT;
    cin>>n;
    for(int i=1;i<n;i++)
    {
        int u,v;cin>>u>>v;
        qwq[u].push_back(v);
        qwq[v].push_back(u);
    }
    dfs(1,0,0);
    maxdep=-1;
    dfs(maxu,0,0);
    cout<<m;
}
```



####  树的重心

> ##### P1395 会议
>
> 有一个村庄居住着 $n$ 个村民，有 $n-1$ 条路径使得这 $n$ 个村民的家联通，每条路径的长度都为 $1$。现在村长希望在某个村民家中召开一场会议，村长希望所有村民到会议地点的距离之和最小，那么村长应该要把会议地点设置在哪个村民的家中，并且这个距离总和最小是多少？若有多个节点都满足条件，则选择节点编号最小的那个点。
>
> ##### 输入格式
>
> 第一行，一个数 $n$，表示有 $n$ 个村民。
>
> 接下来 $n-1$ 行，每行两个数字 $a$ 和 $b$，表示村民 $a$ 的家和村民 $b$ 的家之间存在一条路径。
>
> ##### 输出格式
>
> 一行输出两个数字 $x$ 和 $y$。
>
> $x$ 表示村长将会在哪个村民家中举办会议。
>
> $y$ 表示距离之和的最小值。

**树的重心的定义是:**

对于树上的某个节点 $u$，如果把 $u$ 删掉，这棵树会分裂成若干个连通块. 假设这些连通块中最大的节点数是 $max\_part$.  使得 $max\_part$ 取得最小值的节点 $u$，就是这棵树的重心.

也可以理解为其中一个点作为根到所有子节点的距离之和最小 (不严谨, 因为树最多有两个重心, 但这样比较好记).

我们需要用一次DFS求出树的重心. 我们需要数组 $siz$ 来统计子树大小.

**流程**:

随意选择一个节点作为树的根节点, 任选一个节点 $u$ , 如果把它删除, 通常会分裂为两个部分:

1. **子树 (向下的部分): ** 大小为 $siz[v_1],siz[v_2],…$

2. **祖先 (向上的部分): ** 大小为 $n-siz[u]$

我们需要在DFS回溯的时候, 顺便把每个 $siz[v]$ 都算出来 , 最后取当前节点的每个 $siz[v]$ , 取到最大值. 在这之后, 同样需要一次和 $n-siz[u]$ 的比较, 并取最大值. 这样每个节点所取到的连通块中最大的节点数 $max\_part$ 就可以求出来了. 

下面是DFS的代码实现.

```cpp
int siz[maxn];
int awa[maxn];

void dfs(int u,int p)
{
    //初始时子树加本节点大小只有1
    siz[u]=1;
    int maxx=0;
    for(int v:qwq[u])
    {
        //依旧无向图防止重复遍历
        if(v!=p)
        {
            dfs(v,u);
            siz[u]+=siz[v];
            maxx=max(maxx,siz[v]);//注意是siz[v]
        }
    }
    maxx=max(maxx,n-siz[u]);
    awa[u]=maxx;
}
```

#### 树状数组

假设有一个长度为 $N$（比如 $N = 10^5$）的数组, 需要极其频繁地做两件事：

1. **单点修改**：把第 $i$ 个数加上 $k$ .
2. **区间查询**：求前 $i$ 个数的和 .

这时就需要树状数组 `tree[]` 了. 

`tree[]` 里存储的不是某个元素的值, 而是前面一段区间元素的总和.

而 `tree[i]` 所管辖的距离, 取决于 $i$ 的二进制. 这里就要涉及树状数组的核心: `lowbit(x)`

`lowbit(x)` 的核心作用: 提取出数字 $x$ 二进制下, 最后一个1代表的值.

```cpp
int lowbit(int x)
{
    return x&(-x);
}
```

所以每个 $x$ 管理的是从$x - lowbit(x) + 1$ 到 $x$ 这 $lowbit(x)$ 个元素的和.

如果要对某个元素进行加法操作, 需要对这个元素所有的上级节点同时进行加法操作.

而值得注意的是, $x+lowbit(x)$ 的结果就是 $x$ 的上级节点. 

因为相加后, $x$ 的最后一位会发生进位, 而结果相对应的势力范围就会扩大.

**添加操作:**

```cpp
void add(int pos,int k)
{
    for(int i=pos;i<=n;i+=lowbit(i))
     	tree[i]+=k;
}
```

**查询操作:**

```cpp
void query(int x)
{
    int ans=0;
    for(int i=x;i>0;i-=lowbit(i))
        ans+=tree[i];
}
```









#### 最近公共祖先(LCA)

> ##### P3379 【模板】最近公共祖先（LCA）
>
> 如题，给定一棵有根多叉树，请求出指定两个点直接最近的公共祖先。
>
> ##### 输入格式
>
> 第一行包含三个正整数 $N,M,S$，分别表示树的结点个数、询问的个数和树根结点的序号。
>
> 接下来 $N-1$ 行每行包含两个正整数 $x, y$，表示 $x$ 结点和 $y$ 结点之间有一条直接连接的边（数据保证可以构成树）。
>
> 接下来 $M$ 行每行包含两个正整数 $a, b$，表示询问 $a$ 结点和 $b$ 结点的最近公共祖先。
>
> ##### 输出格式
>
> 输出包含 $M$ 行，每行包含一个正整数，依次为每一个询问的结果。

如果以**暴力思维**来解这个问题, 解法就是:

地位低的儿子顺着树向上爬, 直到爬到和另一个儿子有同等地位, 然后再一起往上爬, 直到爬到同一个节点, 这个节点就是他们的最近公共祖先. 但很明显, 这样做肯定会超时.

##### 倍增法

类似于快速幂的操作, 将过多的爬升次数变现为 2 的 n 次幂. 所以需要事先预处理每个人跳 $2^k$ 的祖先.

用数组 $fa[x][k]$ 存储每个节点 $x$ 向上跳 $2^k$ 的祖先. 用DFS处理如下

```cpp
void dfs(int u,int p)
{
    depth[u]=depth[p]+1;
    fa[u][0]=p;

    for(int i=1;i<=20;i++)
    fa[u][i]=fa[fa[u][i-1]][i-1];

    for(int v:graph[u]) //遍历邻居
    {
        if(v!=p)
        dfs(v,u);
    }
}
```

其中 $fa[u][i]=fa[fa[u][i-1]][i-1]$ 代表每个节点通过跳两次 $2^{k-1}$ , 跳到了 $2^k$.

预处理后, 就是最主要的部分了. 

```cpp
int lca(int u,int v)
{
    if(depth[u]<depth[v]) //默认把u设为较深的点
    swap(u,v);

    for(int i=20;i>=0;i--)//u开始攀升
    {
        if(depth[fa[u][i]]>=depth[v])
        u=fa[u][i];
    }
    if(u==v)return u;     //如果已经相等,直接返回
    for(int i=20;i>=0;i--)//一起攀升
    {
        if(fa[u][i]!=fa[v][i])
        {
            u=fa[u][i];
            v=fa[v][i];
        }
    }
    return fa[u][0];
}
```

##### 距离公式

 关于计算节点的距离, 有一个具体的公式:

$distance(u,v)=dist[u]+dist[v]-2\times dist[lca(u,v)]$

其中 $dist$ 数组记录了使用 dfs 初始化时每个节点到根节点的距离. 这个公式在计算树的最短路时非常重要.

#### 线段树

线段树是一种用处非常广泛, 自由度极高, 理解难度也不小的树性数据结构. 最基本也是应用最广泛的方面就是维护以及处理区间信息, 如 **区间和** 或者 **区间最值** .

相比较于普通的前缀和, 线段树可以在 $O(\log N)$ 时间实现 **单点修改, 区间修改, 以及区间查询** 操作.

**核心思想**

分治. 把一个大问题分割为无数个小问题并分派给下属 (子树).

一般情况下使用一维数组来模拟线段树 (线段树属于平衡二叉树) . 所以会出现典中典的乘二找子树环节.

```cpp
int tree[4*maxn];
int lazy[4*maxn];
int ls(int p)
{return p<<1;}
int rs(int p)
{return p<<1|1;}
```

首先我们看线段树最基本的结构, 这里以求区间和为例.

**push_up 操作**

即为向上汇报操作

```cpp
void up(int p)
{
    tree[p]=tree[ls(p)]+tree[rs(p)];
}
```

**Build 操作 (建树)**

使用递归的方式, 从上到下划分区间, 直到到达叶节点进行赋值, 然后再从下往上, 通过 `up` 函数汇总信息. 

```cpp
void build(int p,int l,int r)
{
    lazy[p]=0;
    if(l==r)
    {
        sum[p]=a[l];
        return;
    }
    int mid=(l+r)>>1;
    build(ls(p),l,mid);
    build(rs(p),mid+1,r);
    up(p);
}
```

**Lazy 标记**

> 如果是单点修改, lazy标记就不必存在

Lazy 标记是区间修改最严厉的父亲. 它就像一个“待办事项”, 当要修改的区间 **完全包围了** 当前节点覆盖的区间时, 我们可以直接修改区间的节点值 (`tree`), 然后打上 lazy 标记, 记录加了多少.

当需要往下查询或者向下修改的时候, 再把标记向下传.

**push_down 操作**

当迫不得已要访问子节点时, 把 lazy 标记下发.

```cpp
void down(int p,int len)
{
    if(lazy[p])
    {
        lazy[ls(p)]+=lazy[p];
        lazy[rs(p)]+=lazy[p];
        tree[ls(p)]+=lazy[p]*(len-(len>>1));
        tree[rs(p)]+=lazy[p]*(len>>1);
        lazy[p]=0;
    }
}
```

**update 操作**

利用包围特性, 打上标记就跑

```cpp
void update(int p,int l,int r,int L,int R,int k)
{
    if(L<=l&&r<=R)
    {
        lazy[p]+=k;
        tree[p]+=k*(r-l+1);
        return;
    }
    //如果没有完全包围,就要向下走,所以需要处理标记
    down(p,r-l+1)
    
    int mid=(l+r)>>1;
    if(L<=mid)update(ls(p),l,mid,L,R,k);
    if(R>mid)update(rs(p),mid+1,r,L,R,k);
    //子节点更新完了,就要重新向上汇总
    up(p);
}
```

**query 操作**

```cpp
int query(int p,int l,int r,int L,int R)
{
    if(L<=l&&r<=R)
    {
        return tree[p];
    }
    down(p,r-l+1);
    int ans=0;
    int mid=(l+r)>>1;
    if(L<=mid)ans+=query(ls(p),l,mid,L,R);
    if(R>mid)ans+=query(rs(p),mid+1,r,L,R);
    
}
```

#### 二维平面

##### 前缀和公式

现在设 $a[i][j]$ 为第 $i$ 行第 $j$ 列的数，$s[i][j]$ 为 $(1, 1)$ 至 $(i, j)$ 的矩阵中的所有数的和，那么：

$$s[x][y] = a[x][y] + s[x - 1][y] + s[x][y - 1] - s[x - 1][y - 1]$$

利用**容斥原理**可以理解上式。

> 如:
>
> $$ \begin{bmatrix} 3 & 7 & 2 \\ 10 & 5 & 8 \\ 4 & 9 & 1  \end{bmatrix}$$
>
> 计算最后一个元素时, 可代入公式看一下



当需要计算某个$$n \times n $$区间内的总和时

可先把上述前缀和数列加出来

然后使用公式:

$$sum = s[x][y] - s[x - n][y] - s[x][y - n] + s[x - n][y - n]$$





##### 差分数组

关于差分数组的预处理, 和一维的差别不大, 只要考虑四个角的变化就行了

```c++
diff[stx][sty]++;
diff[stx][eny+1]--;
diff[enx+1][sty]--;
diff[enx+1][eny+1]++;
```

> **帮助理解的实例**
>
> 假设我们有一个 $3 \times 3$ 的全 0 矩阵，现在我们要执行一个操作：
>
> 将左上角 $(1, 1)$ 到右下角 $(2, 2)$ 的矩形区域全部加 $5$。
>
> ------
>
> **第一步：差分数组的操作 (Update)**
>
> 根据公式 $d[x_1][y_1] += v, d[x_1][y_2+1] -= v, d[x_2+1][y_1] -= v, d[x_2+1][y_2+1] += v$：
>
> - $d[1][1] \leftarrow +5$
> - $d[1][3] \leftarrow -5$ （即 $y_2+1=3$）
> - $d[3][1] \leftarrow -5$ （即 $x_2+1=3$）
> - $d[3][3] \leftarrow +5$ （即 $x_2+1=3, y_2+1=3$）
>
> 此时，**差分数组 $d$** 如下（未列出的位置为 0）：
>
> |       | **1**  | **2** | **3**  |
> | ----- | ------ | ----- | ------ |
> | **1** | **+5** | 0     | **-5** |
> | **2** | 0      | 0     | 0      |
> | **3** | **-5** | 0     | **+5** |
>
> ------
>
> **第二步：利用容斥原理求前缀和还原 (Recover)**
>
> 我们使用公式 $s[i][j] = d[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]$ 逐个计算。
>
> 1. 计算 $s[1][1]$:
>
>    $s[1][1] = d[1][1] + s[0][1] + s[1][0] - s[0][0] = 5 + 0 + 0 - 0 = \mathbf{5}$
>
> 2. 计算 $s[1][2]$:
>
>    $s[1][2] = d[1][2] + s[0][2] + s[1][1] - s[0][1] = 0 + 0 + 5 - 0 = \mathbf{5}$
>
> 3. 计算 $s[1][3]$ (进入减值区):
>
>    $s[1][3] = d[1][3] + s[0][3] + s[1][2] - s[0][2] = -5 + 0 + 5 - 0 = \mathbf{0}$
>
>    (可以看到，从第 3 列开始，$+5$ 被这一列的 $-5$ 抵消了)
>
> 4. 计算 $s[2][1]$:
>
>    $s[2][1] = d[2][1] + s[1][1] + s[2][0] - s[1][0] = 0 + 5 + 0 - 0 = \mathbf{5}$
>
> 5. 计算 $s[2][2]$:
>
>    $s[2][2] = d[2][2] + s[1][2] + s[2][1] - s[1][1] = 0 + 5 + 5 - 5 = \mathbf{5}$
>
>    (注意这里的容斥：$5+5$ 之后减去重复的左上角 $5$，结果依然是 $5$)
>
> 6. 计算 $s[3][3]$ (右下角修正点):
>
>    在这个位置，上方的累加和左边的累加都已经因为之前的 $-5$ 变成了 $0$，最后的 $+5$ 确保了矩阵外围区域全部归零。
>
> ------
>
> **最终还原的矩阵结果**
>
> |       | **1** | **2** | **3** |
> | ----- | ----- | ----- | ----- |
> | **1** | **5** | **5** | 0     |
> | **2** | **5** | **5** | 0     |
> | **3** | 0     | 0     | 0     |
