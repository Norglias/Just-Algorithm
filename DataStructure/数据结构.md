### 并查集

> 并查集是一种用于管理元素所属集合的数据结构，实现为一个森林，其中每棵树表示一个集合,  树中的节点表示对应集合中的元素。
>
> ——摘自 [OI wiki](https://oi-wiki.org/ds/dsu/)

并查集在竞赛中最常用的实现是: 

**把一个集合抽象为一颗树**.

并且树根为该集合的**代表元素**.

**所谓并:**  就是合并元素为一个集合, 合并的实现可以将两个集合共用一个代表元素.

**所谓查:**  就是查找对应元素在哪一个集合下.



##### 查找实现

一般情况下并查集使用数组实现, 其中数组`fa[]`通常用来记录每个节点的**父节点**

最简单的查找方法就是使用递归实现

```cpp
int fa[maxn];

int find(int x)
{
    if(fa[x]==x)
    return x;
    else return find(fa[x]);
}
```

但是这样的话多次查询就比较费力了(时间复杂度$O(nm)$)

所以我们有**路径压缩优化:** (时间复杂度接近于$O(1)$)

第一次查询时, 把所有子节点的父节点**全部标记为代表元素**

这样后面的查询只要一次就行, 但是会破坏树的结构. 但在并查集中我们不关心树的结构, 只关心**代表元素**

**路径压缩优化:**

```c++
int find(int x)
{
    if(fa[x]==x)
    return x;
    else return fa[x]=find(fa[x]); //递归返回的过程中统一父节点
}
```



##### 合并实现

合并就是共用两个集合的代表元素

```c++
x=find(x),y=find(y);
if(x==y) //如果已经是同一个集合的元素, 跳过操作
continue;
fa[x]=y; //合并顺序可以任意
```



##### 种类并查集

> S 城现有两座监狱，一共关押着 $N$ 名罪犯，编号分别为 $1\sim N$。他们之间的关系自然也极不和谐。很多罪犯之间甚至积怨已久，如果客观条件具备则随时可能爆发冲突。我们用“怨气值”（一个正整数值）来表示某两名罪犯之间的仇恨程度，怨气值越大，则这两名罪犯之间的积怨越多。如果两名怨气值为 $c$ 的罪犯被关押在同一监狱，他们俩之间会发生摩擦，并造成影响力为 $c$ 的冲突事件。
>
> 每年年末，警察局会将本年内监狱中的所有冲突事件按影响力从大到小排成一个列表，然后上报到 S 城 Z 市长那里。公务繁忙的 Z 市长只会去看列表中的第一个事件的影响力，如果影响很坏，他就会考虑撤换警察局长。
>
> 在详细考察了 $N$ 名罪犯间的矛盾关系后，警察局长觉得压力巨大。他准备将罪犯们在两座监狱内重新分配，以求产生的冲突事件影响力都较小，从而保住自己的乌纱帽。假设只要处于同一监狱内的某两个罪犯间有仇恨，那么他们一定会在每年的某个时候发生摩擦。
>
> 那么，应如何分配罪犯，才能使 Z 市长看到的那个冲突事件的影响力最小？这个最小值是多少？
>
> ##### 输入格式
>
> 每行中两个数之间用一个空格隔开。第一行为两个正整数 $N,M$，分别表示罪犯的数目以及存在仇恨的罪犯对数。接下来的 $M$ 行每行为三个正整数 $a_j,b_j,c_j$，表示 $a_j$ 号和 $b_j$ 号罪犯之间存在仇恨，其怨气值为 $c_j$。数据保证 $1\le a_j< b_j\leq N, 0 < c_j\leq 10^9$，且每对罪犯组合只出现一次。

上面这道题的人话就是将所有人分成两个集合(或者说是并查集), 两个集合边权的最大值最小.

这道题的一个解法的核心逻辑就是: **敌人的敌人就是朋友**

具体实现是:

1. 先把所有的 $w$ 从大到小排序, 随后开始遍历. 优先把边权较大的两个人分开.
2.  定义一个 $enemy$ 数组, 存储哪两个节点是敌人, 初值为0. 如果没有被赋值, 有如下操作

```cpp
if(!enemy[u])
	enemy[u]=v;
//......
if(!enemy[v])
    enemy[v]=u;
```

​		 如果被赋值, 就找到 $u$ 的敌人 $enemy[u]$ , 并将 $enemy[u]$ 与 $v$ 合并. 对于 $v$ 同理执行一遍.3. 

3. 在循环头部加上判断 $u,v$ 是否合并. 如果合并就把对应的边权和 $ans$ 比较, 取最大值, 从而得到最终答案. 

总实现如下:

```cpp
int n,m,ans;
int fa[maxn];
int enemy[maxn];

int find(int x)
{
    if(fa[x]==x)
    return x;
    else
    return fa[x]=find(fa[x]);
}
struct edge{
    int u,v,w;
};
vector<edge>qwq;

bool cmp(edge a,edge b)
{
    return a.w>b.w;
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0);
    cin>>n>>m;
    for(int i=1;i<=n;i++)
    fa[i]=i;
    for(int i=1;i<=m;i++)
    {
        int u,v,w;cin>>u>>v>>w;
        qwq.push_back({u,v,w});
    }
    sort(qwq.begin(),qwq.end(),cmp);
    int cnt=n;
    for(auto x:qwq)
    {
        int u=x.u,v=x.v,w=x.w;
        if(find(u)==find(v))
        {
            ans=max(ans,w);
            continue;
        }
        if(enemy[u]==0)
        enemy[u]=v;
        else
        {
            int vvv=enemy[u];
            fa[find(vvv)]=find(v);
            cnt--;
        }
        if(enemy[v]==0)
        enemy[v]=u;
        else
        {
            int vvv=enemy[v];
            fa[find(vvv)]=find(u);
            cnt--;
        }
    }
    cout<<ans;
}
```

### 单调栈

 与单调队列类似，单调栈维护的也是一种有序的数据结构。和单调队列的核心差异就是单调栈存储的是对于元素的下标，而不是元素本身。

单调栈有两种：

- 单调递减栈，指的就是栈内存放下标对应元素构成的序列对应的元素单调递减。
- 单调递增栈，指的就是栈内存放下标对应元素构成的序列对应的元素单调递增。

**P5788**模板题要求找到数组元素右边第一个大于它的元素

在寻找右边的时候，需要倒序遍历，以及一个数组 $R$ 存储下标

代码示例如下

```cpp
for(int i=n;i>=1;i--)
{
    //如果栈顶元素小于当前元素，就把它踢掉
    while(!st.empty()&&num[st.top()]<num[i])
        st.pop();
    //如果栈是空的，就说明不存在元素成立，反之设为经过筛选的栈顶
    R[i]=st.empty()?0:st.top();
    st.push(i);
}
```

一开始栈虽然是空的，但倒序遍历可以优先处理右边的元素，当我们处理第 $i$ 个时，它右边的所有元素都已经处理完了。

寻找左边的同理，只不过要改为正序遍历。



### 树

#### 二叉树

> 二叉树是每个节点最多只有两个子节点的特殊树, 所以使用如下方式存储
>
> ```cpp
> struct node{
>     int l,r;
> };
> node tree[maxn];
> ```

##### 求深度

给出一个二叉树, 最基础的求深度方式就是递归遍历. 一般来说根节点为1. 分别遍历左右节点.

求深度代码实现如下

```cpp
void dfs(int pos,int depth)
{
    int l=tree[pos].l,r=tree[pos].r;
    if(l==r&&l==0)
    {
        ans=max(ans,depth);
        return;
    }
    dfs(l,depth+1);
    dfs(r,depth+1);
}
```

##### 前中后序遍历

> ##### 输入格式
>
> 第一行一个字符串，表示该树的中序遍历。
>
> 第二行一个字符串，表示该树的前序遍历。
>
> ##### 输出格式
>
> 单独的一行表示该树的后序遍历.

关于树的遍历, 有很方便的口诀:

- 前序遍历: **根左右**
- 中序遍历: **左根右**
- 后序遍历: **左右根**

已知前中序求后序的方法通常用递归直接打印出来.

首先, 前序遍历的第一个元素一定是根节点. 通过这个元素找到中序遍历中的根节点位置, 此位置的左侧就是左子树, 右边就是右子树. 根据切出的子树长度去切前序遍历的左右子树, 由此递归下去. 两次递归结束后, 再输出根节点即可.

代码实现如下:

```cpp
void dfs(string zhong,string qian)
{
    if(zhong.empty()||qian.empty())
    return;

    char root=qian[0];
    int pos=zhong.find(root);
    string le=zhong.substr(0,pos);
    string ri=zhong.substr(pos+1);
    int l=le.length();
    string ple=qian.substr(1,l);//注意一定要跳过根节点
    string pri=qian.substr(l+1);//剩下的都是右子树

    dfs(le,ple);
    dfs(ri,pri);

    cout<<root;
}
```

##### 特殊情况

当我们知道一个树的前中序或者中后序时, 这个树是可以被唯一确定的. 但如果只知道前后序, 是不能唯一确定树的. 

但这种情况仅会出现在有某个节点仅存在一个儿子, 每有一个这样的节点, 中序遍历的个数便乘二.

> ##### P1229 遍历问题
> ##### 输入格式
>
> 共两行，第一行表示该二叉树的前序遍历结果 $s_1$，第二行表示该二叉树的后序遍历结果 $s_2$。
>
> ##### 输出格式
>
> 输出可能的中序遍历序列的总数，结果不超过 $2^{63}-1$。

关于这个题, 有个技巧, 如果在前序遍历中找到ab, 后序遍历里有ba存在, 就说明a这个节点只有一个儿子.

具体实现如下: 

```cpp
signed main()
{

    int le=qian.length();
    int ans=0;
    for(int i=0;i<le-1;i++)
    {
        string cur=qian.substr(i,2);
        reverse(cur.begin(),cur.end());
        if(hou.find(cur)!=string::npos)
        ans++;
    }
    cout<<(1LL<<ans);
}
```



#### 最近公共祖先(LCA)

> ##### P3379 【模板】最近公共祖先（LCA）
>
> 如题，给定一棵有根多叉树，请求出指定两个点直接最近的公共祖先。
>
> ##### 输入格式
>
> 第一行包含三个正整数 $N,M,S$，分别表示树的结点个数、询问的个数和树根结点的序号。
>
> 接下来 $N-1$ 行每行包含两个正整数 $x, y$，表示 $x$ 结点和 $y$ 结点之间有一条直接连接的边（数据保证可以构成树）。
>
> 接下来 $M$ 行每行包含两个正整数 $a, b$，表示询问 $a$ 结点和 $b$ 结点的最近公共祖先。
>
> ##### 输出格式
>
> 输出包含 $M$ 行，每行包含一个正整数，依次为每一个询问的结果。

如果以**暴力思维**来解这个问题, 解法就是:

地位低的儿子顺着树向上爬, 直到爬到和另一个儿子有同等地位, 然后再一起往上爬, 直到爬到同一个节点, 这个节点就是他们的最近公共祖先. 但很明显, 这样做肯定会超时.

##### 倍增法

类似于快速幂的操作, 将过多的爬升次数变现为 2 的 n 次幂. 所以需要事先预处理每个人跳 $2^k$ 的祖先.

用数组 $fa[x][k]$ 存储每个节点 $x$ 向上跳 $2^k$ 的祖先. 用DFS处理如下

```cpp
void dfs(int u,int p)
{
    depth[u]=depth[p]+1;
    fa[u][0]=p;

    for(int i=1;i<=20;i++)
    fa[u][i]=fa[fa[u][i-1]][i-1];

    for(int v:graph[u]) //遍历邻居
    {
        if(v!=p)
        dfs(v,u);
    }
}
```

其中 $fa[u][i]=fa[fa[u][i-1]][i-1]$ 代表每个节点通过跳两次 $2^{k-1}$ , 跳到了 $2^k$.

预处理后, 就是最主要的部分了. 

```cpp
int lca(int u,int v)
{
    if(depth[u]<depth[v]) //默认把u设为较深的点
    swap(u,v);

    for(int i=20;i>=0;i--)//u开始攀升
    {
        if(depth[fa[u][i]]>=depth[v])
        u=fa[u][i];
    }
    if(u==v)return u;     //如果已经相等,直接返回
    for(int i=20;i>=0;i--)//一起攀升
    {
        if(fa[u][i]!=fa[v][i])
        {
            u=fa[u][i];
            v=fa[v][i];
        }
    }
    return fa[u][0];
}
```

##### 距离公式

 关于计算节点的距离, 有一个具体的公式:

$distance(u,v)=dist[u]+dist[v]-2\times dist[lca(u,v)]$

其中 $dist$ 数组记录了使用 dfs 初始化时每个节点到根节点的距离. 这个公式在计算树的最短路时非常重要.

关于二叉搜索树, 其最基本的特征就是:

1. 若左子树不空, 则左子树上所有结点的值均小于它根结点的值.

3. 左右子树也分别为二叉排序树.
4. 没有权值相等的结点.

如果要处理多个相等元素怎么办? BST和普通二叉树的区别就是多加了一个元素用来存这个元素出现的次数. 同样还需要一个变量 $size$ 存储左右子树加上自身的元素个数, 方便统计排名.

#### 二维平面

##### 前缀和公式

现在设 $a[i][j]$ 为第 $i$ 行第 $j$ 列的数，$s[i][j]$ 为 $(1, 1)$ 至 $(i, j)$ 的矩阵中的所有数的和，那么：

$$s[x][y] = a[x][y] + s[x - 1][y] + s[x][y - 1] - s[x - 1][y - 1]$$

利用**容斥原理**可以理解上式。

> 如:
>
> $$ \begin{bmatrix} 3 & 7 & 2 \\ 10 & 5 & 8 \\ 4 & 9 & 1  \end{bmatrix}$$
>
> 计算最后一个元素时, 可代入公式看一下



当需要计算某个$$n \times n $$区间内的总和时

可先把上述前缀和数列加出来

然后使用公式:

$$sum = s[x][y] - s[x - n][y] - s[x][y - n] + s[x - n][y - n]$$

```c++
diff[stx][eny+1]--;

diff[enx+1][eny+1]++;
```

> **帮助理解的实例**
>
> 假设我们有一个 $3 \times 3$ 的全 0 矩阵，现在我们要执行一个操作：
>
> 将左上角 $(1, 1)$ 到右下角 $(2, 2)$ 的矩形区域全部加 $5$。
>
> ------
>
> **第一步：差分数组的操作 (Update)**
>
> 根据公式 $d[x_1][y_1] += v, d[x_1][y_2+1] -= v, d[x_2+1][y_1] -= v, d[x_2+1][y_2+1] += v$：
>
> - $d[1][1] \leftarrow +5$
> - $d[1][3] \leftarrow -5$ （即 $y_2+1=3$）
> - $d[3][1] \leftarrow -5$ （即 $x_2+1=3$）
> - $d[3][3] \leftarrow +5$ （即 $x_2+1=3, y_2+1=3$）
>
> 此时，**差分数组 $d$** 如下（未列出的位置为 0）：
>
> |       | **1**  | **2** | **3**  |
> | ----- | ------ | ----- | ------ |
> | **1** | **+5** | 0     | **-5** |
> | **2** | 0      | 0     | 0      |
> | **3** | **-5** | 0     | **+5** |
>
> ------
>
> **第二步：利用容斥原理求前缀和还原 (Recover)**
>
> 我们使用公式 $s[i][j] = d[i][j] + s[i-1][j] + s[i][j-1] - s[i-1][j-1]$ 逐个计算。
>
> 1. 计算 $s[1][1]$:
>
>    $s[1][1] = d[1][1] + s[0][1] + s[1][0] - s[0][0] = 5 + 0 + 0 - 0 = \mathbf{5}$
>
> 2. 计算 $s[1][2]$:
>
>    $s[1][2] = d[1][2] + s[0][2] + s[1][1] - s[0][1] = 0 + 0 + 5 - 0 = \mathbf{5}$
>
> 3. 计算 $s[1][3]$ (进入减值区):
>
>    $s[1][3] = d[1][3] + s[0][3] + s[1][2] - s[0][2] = -5 + 0 + 5 - 0 = \mathbf{0}$
>
>    (可以看到，从第 3 列开始，$+5$ 被这一列的 $-5$ 抵消了)
>
> 4. 计算 $s[2][1]$:
>
>    $s[2][1] = d[2][1] + s[1][1] + s[2][0] - s[1][0] = 0 + 5 + 0 - 0 = \mathbf{5}$
>
> 5. 计算 $s[2][2]$:
>
>    $s[2][2] = d[2][2] + s[1][2] + s[2][1] - s[1][1] = 0 + 5 + 5 - 5 = \mathbf{5}$
>
>    (注意这里的容斥：$5+5$ 之后减去重复的左上角 $5$，结果依然是 $5$)
>
> 6. 计算 $s[3][3]$ (右下角修正点):
>
>    在这个位置，上方的累加和左边的累加都已经因为之前的 $-5$ 变成了 $0$，最后的 $+5$ 确保了矩阵外围区域全部归零。
>
> ------
>
> **最终还原的矩阵结果**
>
> |       | **1** | **2** | **3** |
> | ----- | ----- | ----- | ----- |
> | **1** | **5** | **5** | 0     |
> | **2** | **5** | **5** | 0     |
> | **3** | 0     | 0     | 0     |
