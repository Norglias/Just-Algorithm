## 搜索

### 1.BFS

#### 1.马的遍历 (模板)

> ##### 题目描述
>
> 有一个 $n \times m$ 的棋盘，在某个点 $(x, y)$ 上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。
>
> ##### 输入格式
>
> 输入只有一行四个整数，分别为 $n, m, x, y$。
>
> ##### 输出格式
>
> 一个 $n \times m$ 的矩阵，代表马到达某个点最少要走几步（不能到达则输出 $-1$）。

众所周知, 只要提到BFS那大概率离不开队列

BFS的精髓就是层级搜索, 而队列这种先进先出的数据结构就能完美匹配BFS的逻辑

下面是这道题的核心实现

```c++
queue<pair<int,int>>qu;
int dx[]={-2,-2,2,2,1,-1,1,-1};
int dy[]={-1,1,-1,1,2,-2,-2,2};

while (!qu.empty())
{
    for(int i=0;i<8;i++)
    {
        int tx=qu.front().first+dx[i];
        int ty=qu.front().second+dy[i];
        if(tx>0&&tx<=n&&ty>0&&ty<=m&&ju[tx][ty]==false)
        {
            ju[tx][ty]=true;
            ans[tx][ty]=ans[qu.front().first][qu.front().second]+1;
            qu.push({tx,ty});
        }
    }
    qu.pop();
}
```

> 要注意入队出队的操作

相比较于DFS的一条道走到黑 (栈的逻辑) ,BFS更加强调**地板式搜索**.

使用时需要注意他们的区别

下面是完整的代码实现

```c++
int n,m;
int ans[405][405];
bool ju[405][405];
queue<pair<int,int>>qu;
int dx[]={-2,-2,2,2,1,-1,1,-1};
int dy[]={-1,1,-1,1,2,-2,-2,2};


int main()
{
    cin>>n>>m;
    int x,y;cin>>x>>y;
    memset(ans,-1,sizeof(ans)); //别忘了初始化为-
    ju[x][y]=true;ans[x][y]=0;
    qu.push({x,y});
    while (!qu.empty())
    {
        for(int i=0;i<8;i++)
        {
            int tx=qu.front().first+dx[i];
            int ty=qu.front().second+dy[i];
            if(tx>0&&tx<=n&&ty>0&&ty<=m&&ju[tx][ty]==false)
            {
                ju[tx][ty]=true;
                ans[tx][ty]=ans[qu.front().first][qu.front().second]+1;
                qu.push({tx,ty});
            }
        }
        qu.pop();
    }
    for(int i=1;i<=n;i++)
    {
        for(int j=1;j<=m;j++)
        cout<<ans[i][j]<<" ";
        cout<<"\n";
    }
}
```
