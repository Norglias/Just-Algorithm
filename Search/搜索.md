## 搜索

### 1.BFS

#### 1.马的遍历 (模板)

> ##### 题目描述
>
> 有一个 $n \times m$ 的棋盘，在某个点 $(x, y)$ 上有一个马，要求你计算出马到达棋盘上任意一个点最少要走几步。
>
> ##### 输入格式
>
> 输入只有一行四个整数，分别为 $n, m, x, y$。
>
> ##### 输出格式
>
> 一个 $n \times m$ 的矩阵，代表马到达某个点最少要走几步（不能到达则输出 $-1$）。

众所周知, 只要提到BFS那大概率离不开队列

BFS的精髓就是层级搜索, 而队列这种先进先出的数据结构就能完美匹配BFS的逻辑

下面是这道题的核心实现

```c++
queue<pair<int,int>>qu;
int dx[]={-2,-2,2,2,1,-1,1,-1};
int dy[]={-1,1,-1,1,2,-2,-2,2};

while (!qu.empty())
{
    for(int i=0;i<8;i++)
    {
        int tx=qu.front().first+dx[i];
        int ty=qu.front().second+dy[i];
        if(tx>0&&tx<=n&&ty>0&&ty<=m&&ju[tx][ty]==false)
        {
            ju[tx][ty]=true;
            ans[tx][ty]=ans[qu.front().first][qu.front().second]+1;
            qu.push({tx,ty});
        }
    }
    qu.pop();
}
```

> 要注意入队出队的操作

相比较于DFS的一条道走到黑 (栈的逻辑) ,BFS更加强调**地板式搜索**.

使用时需要注意他们的区别

下面是完整的代码实现

```c++
int n,m;
int ans[405][405];
bool ju[405][405];
queue<pair<int,int>>qu;
int dx[]={-2,-2,2,2,1,-1,1,-1};
int dy[]={-1,1,-1,1,2,-2,-2,2};


int main()
{
    cin>>n>>m;
    int x,y;cin>>x>>y;
    memset(ans,-1,sizeof(ans)); //别忘了初始化为-
    ju[x][y]=true;ans[x][y]=0;
    qu.push({x,y});
    while (!qu.empty())
    {
        for(int i=0;i<8;i++)
        {
            int tx=qu.front().first+dx[i];
            int ty=qu.front().second+dy[i];
            if(tx>0&&tx<=n&&ty>0&&ty<=m&&ju[tx][ty]==false)
            {
                ju[tx][ty]=true;
                ans[tx][ty]=ans[qu.front().first][qu.front().second]+1;
                qu.push({tx,ty});
            }
        }
        qu.pop();
    }
    for(int i=1;i<=n;i++)
    {
        for(int j=1;j<=m;j++)
        cout<<ans[i][j]<<" ";
        cout<<"\n";
    }
}
```



### 2.DFS

DFS的一大特点就是递归操作, 拉高了理解的门槛, 而且DFS本身比较灵活, 需要多加练习, 才能找到感觉.

#### 1.P2404 自然数的拆分问题

> ##### 题目描述
>
> 任何一个大于 $1$ 的自然数 $n$，总可以拆分成若干个小于 $n$ 的自然数之和。现在给你一个自然数 $n$，要求你求出 $n$ 的拆分成一些数字的和。每个拆分后的序列中的数字从小到大排序。然后你需要输出这些序列，其中字典序小的序列需要优先输出。
>
> ##### 输入格式
>
> 输入：待拆分的自然数 $n$。
>
> ##### 输出格式
>
> 输出：若干数的加法式子。

**代码实现**

```cpp
//x表示要加的数,
void dfs(int x,int index,int num) //dfs(1,1,0)
{
    if(x==n) //防止单独输出对应的数
    return;
    if(num==n)
    {
        for(int i=1;i<index;i++)
        {
            if(i==1)
            cout<<way[i];
            else
            cout<<'+'<<way[i];
        }
        cout<<"\n";
        return;
    }
    for(int i=x;i<=n-num;i++)
    {
        way[index]=i;
        dfs(i,index+1,num+i);
    }
}
```

主要逻辑就是深搜到底, 然后回溯的时候顺便把剩余情况写入数组.

其中` for(int i=x;i<=n-num;i++)`中的 $n-num$ 最为重要, 他保证了输出结果按字典序, 并且省去了重复情况. 在回溯时省去了不必要的for循环.



#### 2.P2036 PERKET

> 你有 $n$ 种可支配的配料。对于每一种配料，我们知道它们各自的酸度 $s$ 和苦度 $b$。当我们添加配料时，总的酸度为每一种配料的酸度总乘积；总的苦度为每一种配料的苦度的总和。
>
> 众所周知，美食应该做到口感适中，所以我们希望选取配料，以使得酸度和苦度的绝对差最小。
>
> 另外，我们必须添加至少一种配料，因为没有任何食物是只以水为配料的。
>
> ##### 输入格式
>
> 第一行一个整数 $n$，表示可供选用的食材种类数。
>
> 接下来 $n$ 行，每行 $2$ 个整数 $s_i$ 和 $b_i$，表示第 $i$ 种食材的酸度和苦度。
>
> ##### 输出格式
>
> 一行一个整数，表示可能的总酸度和总苦度的最小绝对差。
>
> $(1\le n\le10)$

这个是比较基础的DFS, 没有涉及到较为复杂的回溯问题, dfs过程也很简洁, 只要模拟挑选的过程就行了

下面是代码实现

```cpp
int n,ans=INF;
vector<pair<int,int>>qwq;

void dfs(int pos,int s,int b)
{
    if(pos>=n)
    {
        if(s==1&&b==0)
        return;
        int awa=abs(s-b);
        ans=min(awa,ans);
        return;
    }
    //模拟每一步选或者不选
    dfs(pos+1,s*qwq[pos].first,b+qwq[pos].second);
    dfs(pos+1,s,b);
}
```
