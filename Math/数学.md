### 进制相关

#### 1.格雷码

> 格雷码（Gray Code）是一种特殊的 $n$ 位二进制串排列法，它要求相邻的两个二进制串间**恰好**有一位**不同**，特别地，第一个串与最后一个串也算作相邻。
>
> $n$ 位格雷码不止一种，下面给出其中一种格雷码的生成算法：
> 1. 1 位格雷码由两个 1 位二进制串组成，顺序为：0，1。
> 2. $n + 1$ 位格雷码的前 $2^n$ 个二进制串，可以由依此算法生成的 $n$ 位格雷码（总共 $2^n$ 个 $n$ 位二进制串）按**顺序**排列，再在每个串前加一个前缀 0 构成。
> 3. $n + 1$ 位格雷码的后 $2^n$ 个二进制串，可以由依此算法生成的 $n$ 位格雷码（总共 $2^n$ 个 $n$ 位二进制串）按**逆序**排列，再在每个串前加一个前缀 1 构成。
>
> 综上，$n + 1$ 位格雷码，由 $n$ 位格雷码的 $2^n$ 个二进制串按顺序排列再加前缀 0，和按逆序排列再加前缀 1 构成，共 $2^{n+1}$ 个二进制串。另外，对于 $n$ 位格雷码中的 $2^n$ 个 二进制串，我们按上述算法得到的排列顺序将它们从 $0 \sim 2^n - 1$ 编号。

计算第 $k$ 个格雷码, 有对应公式: 

$$ G(k)=k \oplus (k\gg1)$$ , 其中 $G(k)$ 表示对应的二进制形式

void solve(int n)
{
    b[0]=b[1]=true;
    for (int i = 2; i*i <= n; i++)
    {
        if(!b[i])
        {
            for(int j=i*i;j<=n;j+=i)//注意是j+=i

            }
        }
    }
}

#### 2.欧拉筛法

最基础的欧拉筛需要用到两个数组

```c++
bool isprime[maxn]; //记录是否为素数
int prime[maxn];    //存储素数
int cnt=0;
```

核心思路如下

```cpp
void gprime(int n)
{
    memset(isprime,1,sizeof(isprime));
    isprime[1]=0;
    for(int i=2;i<=n;i++)
    {
        if(isprime[i])
        prime[++cnt]=i;

        for(int j=1;j<=cnt&&i*prime[j]<=n;j++)
        {
            isprime[i*prime[j]]=0;
            if(i%prime[j]==0)
            break;
        }
    }
}
```

一眼看上去和埃氏筛法大差不差, 但欧拉筛法的灵魂就在于

```cpp
if(i%prime[j]==0)
    break;
```

**每一个合数，只被它的“最小质因子”筛掉，且只筛一次**

> 假设我们要筛掉 **12**。
>
> 12 的质因子有 `2` 和 `3`。
>
> 12 的**最小质因子**是 **2**。所以 12 **理应**在 $i=6$ 的时候，被 $2$ 筛掉（$6 \times 2 = 12$）。
>
> **如果不加 `break`，看看会发生什么：**
>
> 当 $i = 4$ 时：
>
> - 先筛 $4 \times 2 = 8$。
> - 接着筛 $4 \times 3 = 12$。（注意！这里用 $3$ 筛掉了 12）。
> - 此时 `4 % 2 == 0`，但我们**没 Break**，继续跑。
>
> 当 $i = 6$ 时：
>
> - 先筛 $6 \times 2 = 12$。（注意！这里用 $2$ **又**筛了一次 12）。
>
> **结果：12 被筛了两次！**
>
> 第一次是 $4 \times 3$（用 3 筛），第二次是 $6 \times 2$（用 2 筛）。这就是浪费。



#### 3.[例题] P1835 素数密度

> ##### 题目描述
>
> 给定 $L,R$，请计算区间 $[L,R]$ 中素数的个数。
>
>    $1\leq L\leq R < 2^{31}$，$R-L\leq 10^6$。
>
> ##### 输入格式
>
> 第一行，两个正整数 $L$ 和 $R$。
>
> ##### 输出格式
>
> 一行，一个整数，表示区间中素数的个数。

由于数据已经到了 $2^{31}$ 的范围, 直接硬用上面的筛法会爆内存的. 这就属于区间小但上限高的优化情况.

因为任意一个合数 $x$ , 必定包含一个不会大于 $\sqrt x$ 的质因子. 所以我们可以先筛出 $\sqrt {2^{31}} (不超过50000)$ 以内的所有质数, 然后遍历每个质数, 找出对应的在 $L, R$ 范围内的倍数, 用一个bool数组标记一下, 最后遍历.

```cpp
bool notprime[50050];
int prime[maxn],cnt;

//range数组用来标记L-R区间范围内的质数情况
//下标i表示数字L+i
bool range[maxn];

void p(int n)
{
   	//此处省略欧拉筛
}

signed main()
{
    int l,r,ans=0;cin>>l>>r;
    
    memset(range,1,sizeof(range));
    if(l==1)
    range[0]=0;
    p(50000);
    for(int i=1;i<=cnt;i++)
    {
        int pcur=prime[i];
        if(pcur*pcur>r)
        break;

        int lll=(l+pcur-1)/pcur*pcur;

        if(lll==pcur)//如果是质数本身,就不能把它筛掉,要乘二
        lll=2*pcur;

        for(int i=lll;i<=r;i+=pcur)
        range[i-l]=0;
    }

    for(int i=0;i<=r-l;i++)
    {
        if(range[i])
        ans++;
    }
    cout<<ans;
}
```

其中寻找大于 $L$ 的第一个 $pcur$ 的倍数, 有一个很方便的技巧.

```cpp
int lll=(l+pcur-1)/pcur*pcur;
```

其中 $$ (l+pcur-1)/pcur $$ 等价于 $$[l/pcur]$$ 即向上取整.



### 质因子分解

在日常刷题中, 遇到质因子分解, 在 $N \le 10^{14}$ 的范围内, 如果不涉及多次查询, 基本使用**试除法**

基本原理就是纯粹而又朴素的暴力. 从 $1$ 枚举到 $\sqrt n$ . 如果可以整除, 就不断的将 $n$ 本身除下去直到除不了.这样就能统计每个质因子的个数了, 同时也消去了 $n$ 中对应的质因子, 避免了后续误除了合数.

下面是最基本的试除法模板, 其中用数组记录了每个质因子的次数

```cpp
void findp(int n)
{
    for(int i=2;i*i<=n;i++)//从2k
    {
        if(n%i==0)
        {
            int count=0;
            while(n%i==0)
            {
                n/=i;
                count++;
            }
            prime[i]=count;
        }
    }
    if(n>1)
    prime[n]++;
}
```





### 最大公约数与最小公倍数(GCD&LCM)

最大公约数采用**欧几里得算法**,最小公倍数是两数乘积除于最大公约数.

也就是说: **两数乘积等于最大公约数乘以最小公倍数**

```c++
//运用了gcd(a,b)=gcd(b,r)的性质,r=a%b
int gcd(int a,int b)
{
    while (b)//辗转相除法
    {
        int temp=a%b;  
        a=b;
        b=temp;
    }
    return a;
}
int lcm(int a,int b,int gcd)
{
    int awa=(a/gcd)*b;//可避免溢出
    return awa;
}
```

并且有如下性质:

$$ gcd(a,b)=k$$, 则有 $gcd(a/k,b/k)=1$



#### 与异或结合的特殊情况

满足$\gcd(x, y) = n$, 要求最小化 $x \oplus y$, 可证明$x \oplus y$的**最小值为n**

如果要找出一种x和y, 首先需要找到大于n的最小的2的幂次 $2^k$ ,

 然后构造$x = n \cdot 2^k$, $y = n \cdot (2^k + 1) = n \cdot 2^k + n$

**验证**：

- **GCD 条件**：$\gcd(n \cdot 2^k, n \cdot (2^k + 1)) = n \cdot \gcd(2^k, 2^k + 1)$。因为连续两个整数互质，所以 $\gcd = n \cdot 1 = n$。符合要求.
- **XOR 条件**：由于 $2^k > n$，二进制下 $n \cdot 2^k$ 相当于将 $n$ 向左移位，其低位全是 0。此时执行加法 $n \cdot 2^k + n$ 等同于按位异或 $(n \cdot 2^k) \oplus n$.
- 因此，$x \oplus y = (n \cdot 2^k) \oplus (n \cdot 2^k \oplus n) = \mathbf{n}$.

**证明**

- **已知条件 1**：$x$ 和 $y$ 都是 $n$ 的倍数，且 $x \neq y$。这意味着它们的差 $|x - y|$ 至少是 $n$（即 $|x - y| \ge n$）。

- **已知条件 2**：设它们的异或值为 $d$，即 $x \oplus y = d$。根据异或的自反性，$y = x \oplus d$。

- **代入不等式**：将 $y$ 代入上面的核心不等式，得到：

  $$| (x \oplus d) - x | = | y - x | \le d$$

**逻辑闭环**：

1. 我们知道 $|x - y| \ge n$。
2. 我们又证明了 $|x - y| \le d$。
3. 连起来就是：**$n \le |x - y| \le d$**。
4. 既然 $n \le d$，那么 $d$ **绝对不可能小于 $n$**。



#### 裴蜀定理

对任意两个整数 $a,b$ (不全为 $0$ ), 裴蜀定理指出:

1. 存在整数 $x,y$ ,使得 $$ ax+by=gcd(a,b) $$ 成立.

2. 对任意 $x,y$ , 一定有 $ax+by$ 是 $gcd(a,b)$ 的倍数.
3. 特别地, 方程 $ax + by = 1$ 有整数解当且仅当 $a, b$ 互质.



##### [例] P4549 【模板】裴蜀定理

> 给定一个包含 $n$ 个元素的**整数**序列 $A$，记作 $A_1,A_2,A_3,...,A_n$。
>
> 求另一个包含 $n$ 个元素的待定**整数**序列 $X$，记 $S=\sum\limits_{i=1}^nA_i\times X_i$，使得 $S>0$ 且 $S$ 尽可能的小。
>
> ##### 输入格式
>
> 第一行一个整数 $n$，表示序列元素个数。  
>
> 第二行 $n$ 个整数，表示序列 $A$。
>
> ##### 输出格式
>
> 一行一个整数，表示 $S>0$ 的前提下 $S$ 的最小值。
>
> 对于 $100\%$ 的数据，$1 \le n \le 20$，$|A_i| \le 10^5$，且 $A$ 序列不全为 $0$。

对于n个整数, 裴蜀定理依然成立. 运用以下性质求n个整数的 $gcd$ 即可

$$ gcd(a,b,c)=gcd(gcd(a,b),c) $$

> 因为要求 $S>0$ , 所以不能把负数放进去计算. 因为 $X_i$ 没有正负要求, 所以全部存入正数即可

代码实现

```cpp
int n;
int num[maxn];

int gcd(int a,int b)
{
    while(b)
    {
        int temp=a%b;
        a=b;
        b=temp;
    }
    return a;
}

signed main()
{
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        int x;cin>>x;
        num[i]=abs(x);
    }
    int awa=gcd(num[1],num[2]);
    for(int i=3;i<=n;i++)
    awa=gcd(awa,num[i]);
    
    cout<<awa;
}
```

### 快速幂

#### 1.基础快速幂

##### 原理:

当求 $a^b$ 时, 我们可以通过 $a$ 自乘自己变成 $a^2$ ,再自乘变成 $a^4$ 

依次类推, 可以表示到 $a^{2^n}$ 

1. 假如要求 $a^{11}$ ，我们可以知道11的二进制是 $(1011)$ 

2. $a^{11} = a^8a^2a^1$  

3. 仔细观察就可以发现, 数字8 2 1对应就是二进制对应位数的对应十进制



**过程:**

- 制作一个 $base$。现在 $base=a$，表示的是，$a^1=a$。待会 $base$ 会变的。

- 制作一个 $ans$，初值 1，准备用来做答案。

- $base$  在每次循环后自乘, 表示 $a^{2n}$ 
- 如果此时b对应的二进制末位为1, 则执行 $ans*=base$



**代码实现:**

```c++
int qpow(int a,int b)
{
    int ans=1,base=a;
    while(b>0)
    {
        if(b&1)
        ans*=base;
        
        base*=base;
        b>>=1;
	}
    return ans;
}
```



##### SP: 关于求余运算

> 求余运算有以下性质:
>
> $$(A+B) \bmod b = (A \bmod b + B \bmod b) \bmod b$$
>
> $$(A \times B) \bmod b = ((A \bmod b) \times (B \bmod b)) \bmod b$$

如果想要快速求出 $a^b$ $mod$  $m$

可在快速幂运算中添加步骤 (基于上述性质二)

```c++
ll qpow(ll a,ll b,ll m)
{
    ll ans=1,base=a;
    while (b>0)
    {
        if(b&1)
        {
            ans*=base;
            ans%=m;
        }
        base*=base;
        base%=m;
        b>>=1;
    }
    return ans;
}
```

这样ans返回的就直接是对应的运算结果, 避免了数字的溢出



#### 2.矩阵快速幂

> 假如给了一个N阶矩阵$$A$$，需要知道 $$A^n$$ 的结果, 应该怎么去计算呢?

实现矩阵快速幂最关键的一步就是了解矩阵乘法

最基础的矩阵乘法, 需要**结构体**构造矩阵.

这种乘法的时间复杂度为$$O(n^3)$$

```c++
ll mod=1e9+7;
struct matrix
{
    ll m[105][105];
    matrix(){
        memset(m,0,sizeof(m));
    }

    static matrix ident() //单位矩阵
    {
        matrix res;
        for(int i=1;i<=n;i++)
        res.m[i][i]=1;
        return res;
    }

    matrix operator*(const matrix &other) const //重载运算符定义矩阵乘法
    {
        matrix res;
        for(int i=1;i<=n;i++)
            for(int k=1;k<=n;k++)
            {
                if(m[i][k]==0)
                continue;
                for(int j=1;j<=n;j++)
                {
                    res.m[i][j]=(res.m[i][j]+m[i][k]*other.m[k][j])%mod;
                }
            }
        return res;
    }
};
```

>  `Matrix operator*(const Matrix &other) const` 其实就是一个函数定义
>
> $$\underbrace{\text{Matrix}}_{\text{1. 返回啥}} \quad \underbrace{\text{operator*}}_{\text{2. 函数名叫啥}} \quad ( \underbrace{\text{const Matrix \&other}}_{\text{3. 参数是啥}} ) \quad \underbrace{\text{const}}_{\text{4. 自身承诺}}$$

注意这里的$$i,j,k$$的顺序, 使用 $$i-k-j$$ 的顺序可以大幅提高运算速度 (虽然都是 $$O(n^3)$$)

下面的写法就跟快速幂差不多了

```c++
matrix qpow(matrix base,ll power)
{
    matrix res=matrix::ident();
    while (power>0)
    {
        if(power&1)
        res=res*base;
        base=base*base;
        power>>=1;
    }
    return res;
}
```



### 线性基

用于处理一大堆数字的异或问题，也可以处理某些特定问题的情况个数（如灯泡的开关）

核心就是一个基底，这个基底可以表示某些数字

最核心的操作就是**插入操作**

```cpp
struct LiBasis //结构体非必需
{
    ll p[65]; //存储线性基
    LiBasis(){
        memset(p,0,sizeof(p));
    }
    void insert(ll x)
    {
        for(int i=62;i>=0;i--)
        {
            if((x>>i)&1) //x的第i位如果不为0
            {
                if(!p[i]) //如果p的位置为空，插入
                {
                    p[i]=x;
                    break;
                }
                x^=p[i]; //不为空，就把这一位消去，变为0
            }
        }
    }

};
```

而检查数字k是否能被基表示的操作如下

```cpp
bool check(ll k)
{
    for(int i=62;i>=0;i--)
    {
        if((k>>i)&1) //逐位比对
        {
            if(!p[i]) //消掉第i位，但没有第i位的守门员
                return 0; //既然没人能消掉这一位，k永远不可能是0
            k^=p[i];
        }
    }
    return 1; //此时k已经被消为0
}
```

**关于线性基的性质：**

- 一个元素个数为$n$的线性基，可以表示 $2^n$ 个数字。而0元素应当存在于任意一个线性基中。所以0元素的存在与否，不对线性基真正的元素个数起作用。

​	   比如线性基$\left \{ 0,1,2 \right \}$和$\left \{ 1,2 \right \}$所能表示的数字均为 $2^2$ 个。

- 而关于一组数据，如果其中一个 $x$ 在循环最后变成了0，即代表没有成功插入，也就能证明这组数据的异或和为0。

- 对于一个线性基，是不可能取出一个异或值为0的子集的，因为元素之间是线性无关的。如果一组数据的异或和为0，那就说明元素个数大于线性基的秩。此时每个元素插入线性基时可能会出现插入失败的情况。



#### 例题：P4301 新Nim游戏

> 传统的 Nim 游戏是这样的：有一些火柴堆，每堆都有若干根火柴（不同堆的火柴数量可以不同）。两个游戏者轮流操作，每次可以选一个火柴堆拿走若干根火柴。可以只拿一根，也可以拿走整堆火柴，但不能同时从超过一堆火柴中拿。拿走最后一根火柴的游戏者胜利。
>
> 本题的游戏稍微有些不同：在第一个回合中，双方可以直接拿走若干个整堆的火柴。可以一堆都不拿，但不可以全部拿走。从第二个回合（又轮到第一个游戏者）开始，规则和 Nim 游戏一样。
>
> 如果你先拿，怎样才能保证获胜？如果可以获胜的话，还要让第一回合拿的火柴总数尽量小。

这题与传统Nim的区别就是第一回合规则的变化。最主要的目标就是无论后手怎么操作都不能把火柴个数的异或和变为0，也就是他能在剩下的堆中构造出一个xor和为0的子集。

所以，在插入过程中，如果插入失败，就把这一堆取走。运用贪心从最大值开始判断。

> 求使所有人获得均等糖果的最小代价。

**证明与解题过程**

因为是环型, 所以每个人都可以向两边传递糖果. 我们可以设 $x_i$ 表示第 $i$ 人向第 $i+1$ 传递了多少糖果 (如果为负值就是接受了多少糖果).

我们的目的是求出代价的最小, 即$$\text{min} \sum_{i=1}^{n} |x_i| = |x_1| + |x_2| + \dots + |x_n|$$



对第一个人:  $$a_1 + x_n - x_1 = avg$$ ,有 $$x_1 = x_n + (a_1 - avg)$$


对第二个人:  $$a_2 + x_1 - x_2 = avg$$ ,有 $$x_2 = x_1 + (a_2 - avg)$$ 

把$x_1$代入, 即有 $$x_2 = x_n + (a_1 - avg) + (a_2 - avg) = x_n + (a_1+a_2-2avg)$$
同理 $$x_3=x_n + (a_1+a_2+a_3-3avg)$$.



综上, 可以得出结论, 令 $C_i$ 为 $(a_k - avg)$ 的前缀和, 即有

$C_i = \sum_{k=1}^{i} (a_k - avg)$

所以 $$\sum_{i=1}^{n} |x_i|=\sum_{i=1}^{n}| C_i + x_n|$$. 因为 $x_n$ 无法直接求出, 我们可以设 $x_n$ 为 $k$ ,

即求 $$\sum_{i=1}^{n} | C_i - k|$$ 的最小值. 由某定理可知 $k$ 取 $C_i$ 的中位数时, 可以取到最小值.



所以最终, 我们需要把 $C_i$ 对应的数组排序, 找出中位数 (位置为 $(n+1)/2$ ) ,然后相减求和就行了.

**代码实现**

```cpp
int n,sum;
int num[maxn];
int awa[maxn];

signed main()
{
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>num[i];sum+=num[i];
    }
    int avg=sum/n;
    for(int i=1;i<=n;i++)
    awa[i]=awa[i-1]+num[i]-avg;
    
    sort(awa+1,awa+n+1);

    int mid=awa[(n+1)/2]; //计算中位数
    int ans=0;
    for(int i=1;i<=n;i++)
    {
        ans+=abs(awa[i]-mid);
    }
    cout<<ans;
}
```
