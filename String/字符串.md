## 字符串

### 字符串哈希

#### 1.进制hash

> ##### 题目描述
>
> 给定 $N$ 个字符串（第 $i$ 个字符串长度为 $M_i$，字符串内包含数字、大小写字母，大小写敏感），请求出 $N$ 个字符串中共有多少个不同的字符串。
>

所谓字符串hash, 就是把字符串映射为一个数字, 并进行比较.

假如给定字符串 `abcd` , 我们可以将对应的位置转换为数字 `1234`

在代码中要转化为具体的数字

```cpp
inline int calc(){
	int sum=0;
	int a[]={1,1,4,5,1,4};
	for(int i=0;i<6;++i)sum=sum*10+a[i];
	return sum;
}
```

这里是十进制表达, 当然, 也可以使用其他不同的进制, 这个进制就叫 **基数 (base)** 

但我们可以想到, 如果字符串很多, 那么就有可能会溢出, 所以我们需要一个模数mod

下面就是hash的核心公式

$$\text{hashh} = \left( \sum_{i=1}^{n} s_i \cdot \text{base}^{n-i} \right) \bmod p$$

而如果模数过小, 则有可能导致数字相等而导致**哈希冲突**, 所以我们通常选择**非常大的质数**作为mod

(我们也可以用**unsigned long long**作为变量类型, 这个类型如果超过了上限会自动取模, 但保险起见加上mod还是好一点)



下面是**进制哈希**的代码实现 

```c++
#define ull unsigned long long
ull mod=212370440130137957ll;
ull hash1[maxn];

ull hhash(string a)
{
    ull ans=0,base=10;
    for(auto &x:a)
    {
        ans=(ans*base+(ull)x)%mod;
    }
    return ans;
}
int main()
{
    int n;cin>>n;
    string awa;
    for(int i=1;i<=n;i++)
    {
        cin>>awa;
        hash1[i]=hhash(awa);
    }
    sort(hash1+1,hash1+n+1);
    int cnt=1;
    for(int i=1;i<n;i++)
    {
        if(hash1[i]!=hash1[i+1])
        cnt++;
    }
    cout<<cnt;
}
```



如果我们想要取子串, 该怎么做?

类似于**前缀和**的操作, 我们可以算出各个区间对应的hash值

```cpp
ull hhh(ull h[],ull p[],int l,int r)
{
    return h[r]-h[l-1]*p[r-l+1];
}
```

h[ ]代表存储的字符串hash值, 而p代表进制数组. 因为不同位置的h[ ]值之间有**进制数差异**, 需要补全



下面是存数据的方式

```cpp
const int ppp=131;

void init(string s,ull h[],ull p[])
{
    p[0]=1;
    h[0]=0;
    for(int i=1;i<=s.length();i++)
    {
        p[i]=p[i-1]*ppp;
        h[i]=h[i-1]*ppp+s[i-1];
    }
}
```



### Trie (字典树)

字典树是一种用来批量存储和管理字符串的数据结构, 通过共享字符串的前缀, 形成一棵树.

- **根节点:** 不存字符, 是所有字符串的起点.
- **边:** 代表一个字符.
- **路径:** 从根节点到某个节点, 路径上所有字符连接起来, 就是某个单词上的前缀. 
- **标记位:** 字典树需要标记一个单词是否终止. 这时就需要标记位, 通常用一个bool值或者计数器 `cnt` 记录.

 我们通常使用二维数组 `ch[N][26]` 来存储字典树, 

其中 `N` 代表**所有单词加起来的总字符数** , 也就是总节点数.

`ch[u][c]=v` 代表: 在节点 `u` 后面, 跟着一个字符 `c` , 通往新节点的编号是 `v` .

> P8306 字典树模板题


### KMP

> ##### 题目描述
>
> 给出两个字符串 $s_1$ 和 $s_2$，若 $s_1$ 的区间 $[l, r]$ 子串与 $s_2$ 完全相同，则称 $s_2$ 在 $s_1$ 中出现了，其出现位置为 $l$。 
> 现在请你求出 $s_2$ 在 $s_1$ 中所有出现的位置。
>
> 定义一个字符串 $s$ 的 border 为 $s$ 的一个**非 $s$ 本身**的子串 $t$，满足 $t$ 既是 $s$ 的前缀，又是 $s$ 的后缀。 
> 对于 $s_2$，你还需要求出对于其每个前缀 $s'$ 的最长 border $t'$ 的长度。
>
> ##### 输入格式
>
> 第一行为一个字符串，即为 $s_1$。 
> 第二行为一个字符串，即为 $s_2$。
>
> ##### 输出格式
>
> 首先输出若干行，每行一个整数，**按从小到大的顺序**输出 $s_2$ 在 $s_1$ 中出现的位置。 
> 最后一行输出 $|s_2|$ 个整数，第 $i$ 个整数表示 $s_2$ 的长度为 $i$ 的前缀的最长 border 长度。

我们需要在主串中找到符合条件的子串, 即模式串, 很容易可以想到暴力的算法, 但暴力的最坏时间复杂度达到了 $O(n \times m)$ . 所以我们需要线性时间复杂度的 KMP算法. 

KMP算法优化的点在于, 它减少了无效的重复匹配. 其中的核心实现就在于`next`数组.

`next`数组的严格定义是:

**模式串 $P$ 中, 从下标 $0$ 到 $i$ 的这个子串, 它的最长 Border 长度**.

我们需要先定义两个指针 $i,j$ 用来标记位置. 初始都为0.

假设我们在主串的 $i$ 和模式串的 $j$ 处发生了失配 (即 $S[i] \neq P[j]$) , 那就说明模式串从 $0$ 到 $j-1$ 的部分是和主串完全匹配的. 这时候我们去查看 `next[j-1]` , 因为这里面存的是**前后缀相等的最长长度**, 所以我们可以直接跳到前缀的末尾, 省去多余的步骤. 

具体操作就是: 让 $j$ 指针直接跳回到 `next[j-1]` 的位置, 然后继续和 $S[i]$ 比较. 如果还不匹配，就继续查表回退, 直到匹配或者 $j$ 退回 $0$. 

```cpp
void kmp(string a,string tar)
{
    int la=a.length(),lt=tar.length();
    if(la<lt||lt==0)
    return;
    vector<int>next=b_next(tar);

    for(int i=0,j=0;i<la;i++)
    {
        while(a[i]!=tar[j]&&j>0)
        j=next[j-1];

        if(a[i]==tar[j])
        j++;

        if(j==lt)
        {
            result[++cnt]=i-lt+1;
            j=next[j-1];
        }
    }
}
```



KMP基本原理讲请了, 接下来就是如何生成`next`数组了. 其实和KMP的流程有一点点像.

首先还是需要定义两个指针 $i,j$ 用来比较前后缀 (比较常规的双指针)

- $i$：表示当前正在计算 `next[i] `(也就是当前子串的尾巴) . 从 $1$ 开始往后扫. 
- $j$：表示当前已经匹配的最长 Border 的长度 (同时也指向前缀的下一个待匹配字符). 

如果不匹配, 说明当前的 Border 无法继续延伸, 我们需要找一个次长的 Border , 执行和KMP一样的$j=next[j-1]$ 操作, 不断回退直到前后缀匹配. 

下面是代码实现

```cpp
vector<int> b_next(string p)
{
    int le=p.length();
    vector<int>next(le,0);

    for(int i=1,j=0;i<le;i++)
    {
        while(j>0&&p[i]!=p[j])
        j=next[j-1];
        if(p[i]==p[j])
        j++;
        next[i]=j;
    }
    return next;
}
```



#### 性质

##### 最小循环节长度

一个字符串的最小循环节长度 $L_{min}$ , 等于字符串长度 $n$ 减去**整个字符串**的最大Border长度 $L$.

即 $$L_{min}=n-next[n-1]$$. ( $n-1$ 是因为 $next$ 的下标是从 0 开始的, 实际对应是字符串最后一位的Border长度)

##### 证明

(Gemini生成)

根据 Border 的定义：

**前缀 $S[0 \dots L-1]$ 与 后缀 $S[n-L \dots n-1]$ 完全相同。**

现在，我们想象有两根完全一样的纸带 $S$。我们把下面那一根纸带向右滑动，直到它的**前缀**和上面那一根的**后缀**对齐：

- **滑动的距离**：因为对齐的部分长度是 $L$，所以我们向右滑动的距离就是 $d = n - L$。
- **重叠的部分**：因为前缀等于后缀，所以重叠的这 $L$ 个字符是**完全重合**的。


在重叠区域里，对于任何一个位置 $i$，由于两根纸带在这一点是对齐的，意味着：

**上面纸带的第 $i$ 个字符 = 下面纸带的同一个位置。**

但下面纸带是上面纸带右移 $d$ 位得到的，所以下面纸带在该位置的字符，其实是原串的第 $i-d$ 个字符。

换句话说：$S[i] = S[i-d]$。

这个等式意味着什么？**每隔 $d$ 个字符，字符就会重复出现**. 

可以根据样例 `cabcabca` 来去理解证明.
